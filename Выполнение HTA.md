# Связи процессов и интерпретация команд

Совпадение ProcessGuid у нескольких типов событий связывает действия одного экземпляра. Для связи родителя и потомка сопоставляются ProcessGuid родителя и ParentProcessGuid потомка.

| **Родитель**   | **Потомок**              | **Записи**         |
| -------------- | ------------------------ | ------------------ |
| mshta.exe      | powershell.exe           | 1510 → 1511        |
| powershell.exe | powershell.exe           | 1511 → 1513        |
| powershell.exe | cmd.exe                  | 1513 → 1525        |
| cmd.exe        | powershell.exe и ftp.exe | 1525 → 1535 и 1539 |
| ftp.exe        | supply.exe               | 1539 → 1540        |
| supply.exe     | supply.exe               | 1540 → 1545        |

| Поле                  | Что означает                                                                                                                                |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **UtcTime**           | Время события в UTC                                                                                                                         |
| **User**              | Пользователь, от имени которого запущен процесс                                                                                             |
| **IntegrityLevel**    | Уровень целостности процесса: например, `Medium` — обычный, `High` — повышенный, `System` — системный. Помогает оценить контекст привилегий |
| **ParentImage**       | Полный путь к программе, которая запустила этот процесс — его **родителю**                                                                  |
| **Image**             | Полный путь к запущенной программе                                                                                                          |
| **CommandLine**       | Команда запуска текущего процесса вместе с аргументами                                                                                      |
| **ParentCommandLine** | Команда, с которой был запущен родительский процесс                                                                                         |
| **ProcessGuid**       | Уникальный идентификатор этого экземпляра процесса                                                                                          |
| **ParentProcessGuid** | Уникальный идентификатор его родительского процесса                                                                                         |

Запуск PowerShell с закодированной командой с целью скрытие скрипта.  PowerShell был открыт сценарием updater.hta.
Внешний слой Base64 содержал скрипт, который запускал второй PowerShell в скрытом окне. Второй PowerShell распаковывал вложенный скрипт из Base64 и GZip. Тот выделял память через `VirtualAlloc`, копировал туда **354 байта машинного кода** и запускал их через `CreateThread` внутри самого PowerShell.В машинном коде указан адрес `192.168.1.11:1234`. Код открывал TCP-соединение и был рассчитан на получение и запуск следующей части кода в памяти.

![](attachment/Pasted%20image%2020261115220142.png)cmd записал supply.exe на диск.
- **`-c`**  сокращение от `-Command`. Говорит `powershell.exe` выполнить то, что написано дальше.
- **`Invoke-WebRequest`**  команда PowerShell, которая отправляет веб-запрос и получает ответ сервера.
- **`-Uri`** параметр, задающий адрес запроса. `http://192.168.1.11:6969/supply.exe`
Сохранение ответа в C:\Windows\Temp\supply.exe.
Экземпляры supply.exe инициировали 198 соединений к 192.168.1.11:8080. В аргументах появлялись `ipconfig`, `whoami`, а позже  упоминания JuicyPotato и nc.exe.

**Juicy Potato** — это популярный инструмент и локальный эксплоит для операционных систем Windows, предназначенный для повышения привилегий

Поздние командные строки содержат признаки попытки повысить привилегии. На хосте зафиксированы 404 запуска `supply.exe` с разными `ProcessGuid` и одинаковым SHA-256. Все они шли с уровнем `Medium`. Чтобы установить, что передавалось по сети и получил ли кто-то повышенные права, нужны дополнительные данные, например сетевой захват и журналы Windows Security или EDR.

**1. Получение файла `.hta`**
Выявляет запуск PowerShell дочерним процессом mshta
index="system_logs"  
| spath  
| rename Event.System.EventID AS EventID Event.EventData. _AS_  
| search EventID=15 AND TargetFilename = "*.hta:Zone.Identifier"

**2. Попытка изменения переменной COMSPEC через командную строку**

Выявляет командную строку, содержащую присваивание COMSPEC пути к EXE во временном каталоге. Переопределение командного интерпретатора может использоваться для выполнения другого бинарника.

index="system_logs"
| spath
| rename Event.System.EventID AS EventID Event.EventData.* AS *
| search EventID=1
| regex CommandLine="(?i) \ \bset \ \s+ \ "?comspec \ \s*="

**3. Большое количество исходящих соединений на 8080**

Выявляет не менее 10 исходящих TCP-соединений к порту 8080 в одной календарной минуте от одинакового пути программы на одном хосте к одному адресу.


| search EventID=3 Protocol=tcp Initiated=true DestinationPort=8080
| bin _ time span=1m
| stats count AS Connections
        values(EventRecordID) AS EventRecordIDs
        BY _ time Computer Image DestinationIp DestinationPort
| where Connections>=10

**4. Разведка и возможное использование JuicyPotato**
Одиночный запуск `whoami` или `ipconfig` может быть легитимным действием администратора, но запуск нескольких разных утилит разведки подряд с одного хоста за короткое время  это почти гарантированный признак работы скрипта или злоумышленника.

| search EventID=1
| rex field=CommandLine "(?i)\\b(?<Tool>whoami|systeminfo|netstat|net1|net|nltest|ipconfig|tasklist|quser|qwinsta|arp|route|nslookup)(?:[.]exe)?\\b"
| eval Tool=lower(Tool)
| eval Potato=if(
    match(CommandLine,"(?i)\\b(juicypotato|juice|juicy)[.]exe\\b"),
    1,0)
| where isnotnull(Tool) OR Potato=1
| stats dc(Tool) AS ToolCount
        values(Tool) AS Tools
        sum(Potato) AS PotatoMentions
        values(EventRecordID) AS EventRecordIDs
        BY Computer Image
| where ToolCount>=2 OR PotatoMentions>0

Алерт обнаружит:

- минимум **две разные утилиты разведки** в командных строках одного исполняемого файла на одном компьютере за выбранный период;
- либо упоминание `JuicyPotato.exe`, `juice.exe` или `juicy.exe`
